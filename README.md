# tgrep Agent Plugin

## Install in VS Code

1. Open the Command Palette.
2. Run **Chat: Install Plugin From Source**.
3. Enter `https://github.com/MiguelElGallo/st`.
4. Select **tgrep** if prompted, then start a new chat.

[![Watch the VS Code installation video](marketing/linkedin-tgrep-videos/output/tgrep-vscode-linkedin-thumbnail.png)](marketing/linkedin-tgrep-videos/output/tgrep-vscode-linkedin-1080x1350.mp4)

## Install in Codex

```sh
codex plugin marketplace add MiguelElGallo/st
codex plugin add tgrep@tgrep
```

Start a new Codex task after installation.
