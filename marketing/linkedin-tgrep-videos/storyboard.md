# tgrep LinkedIn videos

Two caption-first, 24-second videos show the verified installation flow and the
same first-use prompt for the tgrep Agent Plugin. Both use a 1080×1350 (4:5)
LinkedIn feed canvas.

| Time | Purpose | On-screen message |

## Claim boundaries

- The videos say tgrep **can** reduce waiting and broad context. They do not
  claim measured percentage improvements.
- “Fewer tokens” refers to giving the agent focused matches instead of broad,
  noisy file context; actual usage depends on the repository and workflow.
- The UI is an illustrative animation. The commands, URL, plugin name, tool
  names, and example prompt are taken from the repository documentation.
- The plugin is community maintained and is not affiliated with or endorsed by
  Microsoft.

## Voiceover

### VS Code

Install tgrep in VS Code in a few simple steps. Open the Command Palette, choose
Chat: Install Plugin From Source, and paste the repository URL. Start a new
chat, build the index once, then search with focused results. That can mean less
waiting, fewer tokens spent on broad context, and more precise repository
exploration.

### Codex

Add tgrep to Codex with two commands. Register the marketplace, install the
plugin, then start a new task in your repository. Ask Codex to build the index
and find the symbol you need. Focused, indexed results can mean less waiting,
fewer tokens spent on broad context, and more precise answers.
